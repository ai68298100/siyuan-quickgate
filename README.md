## 新的产品定位

小驴快门不再只为 Quicker 提供一个外部命令入口，而是作为**小驴生态联动中枢**：在思源内部统一能力发现、命令调用、上下文快照、跨插件事件与组合流程；Quicker、手机快捷指令、脚本和未来客户端都复用同一套公开契约。它服务的插件范围是：小驴雷切、小驴打卡、小驴拾遗、小驴人脉、小驴管家、小驴闪卡、小驴考试，以及后续加入的小驴插件。

中枢只依赖插件公开注册的能力和桥方法，不读取其他插件私有存储。插件缺席、未就绪或版本不兼容时，按能力降级并给出诊断结果；具体能力清单与边界见 [本轮审查与收敛建议](docs/09-本轮审查与收敛建议.md)。

## 建议的推进顺序

1. **P0（零开发，当天可用）**：按 [动作蓝图](docs/03-动作蓝图.md) 搭 4 个通用动作（快速捕获、划词摘录、全局快查、打开今日日记）+ 按 [超级面板方案](docs/05-超级面板方案.md) 搭综合启动器（先跑纯内核降级版）。
2. **P1（先做生态中枢，再接 Quicker）**：按 [快门插件设计](docs/06-小驴快门-配合插件设计.md) 做公开能力注册、健康检查、命令/上下文/事件/工作流骨架，再接 Quicker 数据透传适配器。打卡、人脉及后续五款插件不各自重复实现外部桥；[桥协议](docs/02-小驴桥协议-v1.md) 作为无快门时的直连兜底。
3. **P2（锦上添花）**：手机快捷指令经 Quicker 内置 HTTP API（`POST /api/exec`，端口 668）远程触发；快门 v1.5 广播通道或 v2 内核插件同步通道（≤300ms）；雷切工作台挂载 Quicker 动作卡片。
