# 隐私说明 — 数据流向（Privacy）

> 一句话：**小驴快门不外传任何数据。所有数据流都发生在你的电脑与你自己配置的服务之间。**
> 红线（与 docs/contracts/safety-gate-contract.md 同源）：外部面默认关、不读任何插件私有存储、
> 无 Token 必须被 401/403 拒绝、未知不得改写为成功、不自带模型服务。

## 数据流向图

```
┌─────────────────────────────── 你的电脑 ───────────────────────────────┐
│                                                                        │
│  Quicker 动作 ──HTTP(127.0.0.1:6806)──▶ 思源内核 ◀── 思源同步 ──▶ 你配置的  │
│       │                                 ▲            （可选）        同步服务商 │
│       │ 桥文件读写                        │                             │
│       ▼                                 │                             │
│  data/storage/petal/siyuan-quickgate/   │                             │
│  （commands/results/audit/state）        │                             │
│       ▲                                 │                             │
│  MCP stdio 代理（node 进程，本机）────────┘                             │
│       ▲                                                                │
│  Claude/Cursor 等 AI 客户端（本机进程）                                  │
└────────────────────────────────────────────────────────────────────────┘
                ❌ 快门自身没有任何云端、遥测、统计上传
```

## 各类数据在哪里

| 数据 | 位置 | 是否随思源同步 | 说明 |
|---|---|---|---|
| 桥命令/回执 | `<工作空间>/storage/petal/siyuan-quickgate/bridge/` | 视你的同步配置 | 命令正文来自外部调用方（你自己/AI），滚动压缩 |
| processed 台账 | `data/storage/petal/.../bridge-state.json` | 同上 | 仅 id+时间戳，无正文 |
| 设置 | `data/storage/petal/.../bridge-settings.json` | 同上 | 含黑名单/开关；**Token 不存这里** |
| API Token | `%APPDATA%\siyuan\env`（本机明文，思源自身机制） | 否 | 只存本机动作配置；不上传 |
| 审计日志 | 内存 + `audit.json`（导出才落盘） | 否 | 只记 op/状态/耗时，**无正文无 Token** |
| 事件物化 | 各来源插件桥目录 `events.ndjson` | 同上 | 打卡公开事件（约定字段），非私有存储 |

## 外部端点（仅这些，且都是你自己配置的）

1. **思源内核** `127.0.0.1:6806`（或你的自定地址/HTTPS）——唯一业务端点。
2. **AI 生成 SQL（P0-3 实验分支）**：走**思源内置 AI**（`/api/ai/chatGPT`）→ 请求最终发往**你在思源里配置的 AI 提供商**。快门不经手密钥、不内置任何模型服务。
3. **Quicker 668 HTTP API（SY·反向触发）**：本机 Quicker 自己的服务，非外部。

## 释放/清理

- 卸载快门：`data/storage/petal/siyuan-quickgate/`（含桥与审计）随思源插件数据删除；思源笔记数据不受影响。
- 「清除我的数据」= 删上述两个目录即可（桥目录在 `storage/petal/`，设置在 `data/storage/petal/`）。
- 诊断包（设置页导出）：脱敏设计，不含 Token/正文/个人路径；粘贴给他人前可自查（`docs/FAQ.md §7` 自检工具）。
