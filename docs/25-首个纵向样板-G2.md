# 首个纵向样板（G2 · §18.3 R125 · v0 规格）

> 目的：按 R125"只选一个"的纪律，定义首个纵向闭环的全部要素；验收 = 其他 P0 功能不抢占样板资源、每级门槛有独立证据、真实使用后才扩大功能面。
> 状态：v0 规格（选型与门槛已定；**唯一待用户项 = §7 真实自用观察**）。

## 1. 样板选型（R125-G2 第一条的评估与推荐）

候选 = docs/03 P0 蓝图五件。评估维度：依赖完备度 / 写风险 / 回执可验证性 / 手动等价路径清晰度。

| 候选 | 依赖完备度 | 写风险 | 回执可验证 | 结论 |
|---|---|---|---|---|
| **SY·划词摘录（P0-2）** | ✅ 全（Token/内核 appendBlock/收集箱 ID 可配） | 低（单次 append，目标显式） | ✅ 追加后 SQL 查块 ID 即证 | **✅ 选定** |
| SY·快速捕获（P0-1） | ✅ | 低 | ✅ | 备选（与划词共用目标位置，二选一） |
| SY·打开今日日记（P0-4） | ✅ | 极低（纯导航） | ⚠️ UI 效果无回执 | 不选作首个（验证性弱） |
| SY·剪贴板图片入库（P0-5） | ⚠️ 需图片资产上传链 | 中 | ⚠️ | 不选（多一层资产依赖） |
| SY·汇总日记待办 | ⚠️ 需 readDailyStatus+SQL 组 | 只读 | ✅ | 不选（非捕获闭环） |

## 2. 四组件定义

| 组件 | 选定 | 依赖与验证等级 |
|---|---|---|
| 捕获入口 | Quicker 划词（选中文本 → 快捷键/侧键） | Quicker V2（用户已装）【E4：环境实证】 |
| 目标位置 | 收集箱文档（用户配置 `收集箱文档ID`，默认日记笔记本下收集箱） | ID 由用户首跑配置【E4：ID 真实存在】 |
| 只读查询 | 追加后 `SELECT id,content FROM blocks WHERE id='<returned>'` 核验 | 内核 SQL（R25 已实证）【E4】 |
| 回执核验 | appendBlock 返回块 ID → 查询命中 → 结果卡"已入收集箱" | —— |

## 3. 样板结果卡（R125-G2 第二条）

| 项 | 内容 |
|---|---|
| 用户目标 | 在任意应用选中一段文字，一键存进思源收集箱 |
| 输入来源 | 系统剪贴板/选区（Quicker 文本变量） |
| 成功证据 | 内核返回块 ID + SQL 回查命中 + Quicker 通知"已入收集箱" |
| 失败恢复 | 思源未启动 → 提示启动；Token 失效 → 自动重读 env/引导手填；ID 失效 → 引导重新配置 |
| 未知处理 | HTTP 成功但查询未命中 → 结果卡显式"未知：请手动检查收集箱"（C1 unknown 语义） |
| 手动替代 | 复制 → 切窗口 → 粘贴到思源（永远可用；AI/自动化失败不阻断） |
| 下一步 | 首成功后记录用时（§7），再决定扩大（快速捕获/图片/更多目标） |

## 5. 四级门禁（R125-G2 第四条）

| 级 | 门槛 | 独立证据 |
|---|---|---|
| G2-首成功 | 用户按文档搭完，第一次"选中→入箱→通知"成功 | 用户一句话确认 |
| G2-最小可用 | 连续 3 天日常使用 ≥1 次/天；失败均可恢复 | 用户记录（§7 表） |

| G2-可回滚 | 卸载动作后无残留影响（收集箱内容仍在）；重装可复现 | 卸载→重装演练 |

## 6. 异常样例集（R125-G2 第五条，每类有用户可执行下一步）

| 样例 | 期望 | 用户下一步 |
|---|---|---|
| 正常 | 通知"已入收集箱"+ 块可查 | — |
| 拒绝（401） | 提示 Token 失效 | 重置令牌/重跑首跑向导 |
| 超时（无响应） | 提示"未知，请手动检查"+ 不自动重试 | 看收集箱；在则忽略，不在则重按 |
| 重复触发 | 两块内容（appendBlock 天然非幂等）→ 结果卡提示"已追加 2 次" | 手动删多余块（未来登记 idempotency 写 op 候选） |
| 目标删除 | ID 失效报错 | 重新配置收集箱 ID |
| 空选区 | Quicker 侧拦截，不发起请求 | 重新选择 |
