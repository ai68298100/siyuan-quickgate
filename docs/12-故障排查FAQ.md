# 故障排查 FAQ

> 症状 → 原因 → 解法。持续补充（兜底循环 C 会把新案例收进来）。

## 令牌与连接

| 症状 | 原因 | 解法 |
|---|---|---|
| 所有动作报「思源未运行」 | 内核未启动 / 端口不对 | 启动思源；SY_URL 用默认 `http://127.0.0.1:6806`（思源默认端口——早前"1568"记录已作废） |
| 状态码 401/403 | Token 失效 | 思源「设置→关于→重置令牌」后复制新值；动作在 401 时会先自动重读 `%APPDATA%\siyuan\env`，再引导手填 |
| 换了电脑动作全失效 | 本机 env 与动作配置都没有 Token | 重跑首跑向导（面板设置 → 重新配置） |
| 公司代理环境全部连接失败 | 系统代理拦截 127.0.0.1 | 代理软件把 `127.0.0.1/localhost` 加入直连白名单【待实测确认】 |

## 写入与查询

| 症状 | 原因 | 解法 |
|---|---|---|
| `do not exist` / not exist | 块或文档 ID 失效（被删/移动） | 重新选择目标文档；SY·诊断会检查收集箱是否存在 |
| 写入后立刻查询查不到 | 索引异步（秒级延迟） | 动作已内置等待/重试；手写脚本时 sleep 1s |
| appendBlock 报「叶子块」 | parentID 传了段落/标题 | 改传文档 ID，或用 insertBlock+previousID |
| 搜索结果与预期不符 | 全文搜索是分词模糊匹配 | 精确需求用 `sql:` 前缀；SQL 里 `LIKE '%词%'` |

## 快门桥

| 症状 | 原因 | 解法 |
|---|---|---|
| 桥命令全部 `timeout` | 桥未开启 / 思源未运行 / 轮询挂了 | 快门设置确认桥开关；跑 `lv-cli.mjs ping`；看设置页「最近回执」 |
| 回执 `expired` | 命令发出后 TTL 内没被消费（桥关着/思源关着） | 开桥后重发；确需长延迟消费就加大 ttlMs |
| 回执 `rejected: 用户未确认` | 确认框 30 秒无人点 | 思源在后台时确认框会尝试前置激活；保持思源可见 |
| 同一命令执行了两次 | 客户端超时后换了新 id 重试（违反契约） | 客户端禁止换 id 重试；`commands.run` 等待 ≥35s |
| 多设备同时开思源，命令执行位置不定 | petal 目录随同步复制（协议诚实边界） | 发命令时只开一台；或等 spike⑨ 结论迁到 storage/local |
| 想丢弃积压命令 | 队列堆积 | 快门设置 → 清空命令队列 |
| 桥"看起来在跑"但行为异常，说不清哪一环 | 需要一次性快照 | 设置页「导出诊断包」（脱敏 JSON：设置+统计分账+审计尾部，贴给维护者/存档）；「队列状态」看累计执行分账与平均耗时 |
| 想确认装的小驴插件版本和清单是否一致 | 升级后能力对不上 | 设置页「生态清单版本」按钮：manifest 校准版本 × 实装版本逐插件对照 |

## 数据与安全

| 症状 | 原因 | 解法 |
|---|---|---|
| 误改/误删了块 | API 写入无回收站 | 思源「数据历史/快照」恢复；批量写动作前可手动打快照（`/api/repo/createSnapshot`） |
| 怀疑 Token 泄露 | 分享了截图/日志 | 思源重置令牌；检查动作配置与日志文件（%TEMP%\sy-quicker.log） |
| 打卡记录重复 | 客户端违反幂等契约（换 id 重试） | 上游修复；打卡侧 `source+externalRef` 会自动去重正确实现的重试 |
