|---|---|---|---|

## 3. 决策

1. **天数维度（R-A）立项但默认关**：实现成本极低且默认零行为变化；不进设置页（改 bridge-settings.json 手工字段，normalize 加可选字段 + 文档）。
2. **R-B 随下一轮 UI 轮顺带落地**（载体明细卡扩展）。
3. **R-C 暂缓**（上文触发条件制——L458 先例：沉默候选项写明触发条件才叫清算）。
4. L604 的 cursor/分页：结果中心分页已实现；events 分页待消费方出现再说（门槛后）。

## 4. 验收（R-A/R-B 实现时对勾）

1. retentionDays=30 时：构造 30 天前 events/results 行 → 下次追加后被裁剪；retentionDays=0（默认）行为与现状逐字节一致。
2. 载体明细卡正确显示坏行计数（构造坏行注入验证）。
3. 全量备份/恢复不受 retentionDays 影响（备份仍含裁剪前的全量现状）。
