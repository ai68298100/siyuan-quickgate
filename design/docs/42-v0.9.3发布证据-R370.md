## 鉴权前置条件与未决缺口

首次无访问授权码的靶场：无凭据私有请求 HTTP 200 / recorded，错误 Token HTTP 401，正确 Token 成功。配置访问授权码后，无凭据请求 HTTP 401。原负向断言保持不变，没有把 HTTP 200 当成安全通过。

上游 [v3.8.6 plugin/server.go](https://github.com/siyuan-note/siyuan/blob/v3.8.6/kernel/plugin/server.go) 在转给插件前移除 Authorization；SDK 请求上下文没有可信认证来源字段。快门当前继承宿主鉴权，不自行猜请求是否携带有效 Token。外部使用前必须配置思源访问授权码并实测匿名被拒绝；独立强制 Token 的缺口在 TODO §28 保留 P0 上游阻塞。

启动器现在只在自有隔离工作区生成随机访问授权码，不打印该码；前端通过宿主登录。容器 CI 同步预置访问授权码，移除 bypass。用户在用工作区的鉴权配置没有被自动修改。
