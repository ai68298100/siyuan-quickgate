## 1. 各家机制速览

| 产品 | 核心机制 | 对快门可借鉴点 |
|---|---|---|
| Drafts | 一切从文本框开始（先写后决定去向）；每条草稿有唯一标识，动作链可「追加/打开原文/再处理」 | **先写后分发**：面板输入即草稿，去向（日记/收集箱/任务）后选 |
| flomo | `#标签` 内联标记；卡片流按标签/时间回看；"仅记录，不整理"哲学 | 内联 `#标签` 解析为块标签或引用 |
| Obsidian QuickAdd | 捕获目标可为"追加到指定文档尾部/头部"，模板变量 `{{value}}`/`{{date}}` | 捕获目标可选（日记/收集箱/任意文档 id） |
| Apple 备忘录 | 锁屏/控制中心一键直达输入框；自动带回时间与位置元数据 | 入口可达性：全局热键（已有 Ctrl+Alt+P）+ Quicker 一键（已有动作） |

## 2. 交叉结论（G3-04 完整化排序）

1. **块 id 回执面**：appendDailyNoteBlock 返回块 id——捕获成功后应提供「打开原文」（openTab 到日记文档）与「复制块引用」（`(())` 语义）——数据已有，纯 UI 增量。
2. **目标二选一**（日记 / 收集箱）：config.discover 已同时发现两者；表单一个下拉即可，无需新 op。
3. **`#标签` 解析**：有价值但涉及标签语义（块 tag vs 文本），需与上游打卡/拾遗对齐——**暂缓，登记观察**。
4. **先写后分发**（Drafts 模式）：与现行"无匹配→兜底捕获"相反方向；等恢复中心/结果中心稳定后再评估。
