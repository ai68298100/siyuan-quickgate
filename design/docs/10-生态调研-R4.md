## 2. 与快门的对照修正（L561 矩阵第三行改写）

此前口径「思源原生 MCP=竞品」**不完整**：

| 场景 | 关系 |
|---|---|
| 内置 MCP 服务器（思源自带 tools） | 重叠面=思源原生操作；**不重叠**=小驴生态透传/工作流/收藏/模板 |
| 内置 Agent + **外部 MCP 接入** | **快门 MCP（26 工具）可注册为 Agent 能力源**——思源内的 AI 助手由此获得记打卡/记人脉/跑工作流/查收藏的能力，且受 Agent 侧 authorizer/approver 管控 |

**结论**：快门 MCP 从「与内置 MCP 并列的替代品」升级为「内置 Agent 的能力扩展源」——这是分发渠道级的差异。
