## 已实现行为与证据

快速捕获提取为 `QuickCaptureService`：只从公开内核 API 检查笔记本、日记配置和收集箱文档；不自动创建收集箱。预览显示实际笔记本、文档或日记模板与完整 Markdown；内容和时间前缀在预览时固定。确认后再次检查，同一预览仅允许一次执行尝试；发现目标变化、跨日、过期或读取失败时零写入。只有成功后记住去向。

日记路径由内核按笔记本上下文渲染。`renderSprig` 仅接收 template，不能将其输出冒充按笔记本渲染的最终路径；因此界面明确显示模板和可能创建日记的影响，不宣称锁定某条物理路径。日记原文从本次块事务回执的 parentID 定位，不再全局按日期猜文档。依据：[CreateDailyNote](https://github.com/siyuan-note/siyuan/blob/v3.8.6/kernel/model/file.go)、[appendDailyNoteBlock](https://github.com/siyuan-note/siyuan/blob/v3.8.6/kernel/api/block_op.go)、[renderSprig](https://github.com/siyuan-note/siyuan/blob/v3.8.6/kernel/api/template.go)。

写请求没有完整回执时保持 unknown，界面提示人工核查并关闭再次提交入口；不能证明未写入，也不自动重试。首跑样例写入共用核验与确认，并保存 unknown 状态；测试块的删除方式明确为在目标文档手动删除，不宣称向导提供了撤销按钮。

- E3：42 文件 / 323 测试与离线 MCP 协议 6/6；回归覆盖零写入预检、ID/结构错误、目标变动、过期/跨日、单次确认、unknown 不重发、示例参数与账本解析。
- E3 浏览器宿主替身：选择去向零写入；确认一次写入后才记住去向；unknown 无成功卡且提交关闭；两个复制入口零派发，错型 docIds 点名/聚焦且零复制。
