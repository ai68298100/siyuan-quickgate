> 方法：Web 检索 MCP 规范与宿主实践（证据等级 E1 外部资料；标注 URL）。
> 结论导向：**快门 MCP 面（26 tools）的对齐动作与投影策略**。本轮 2 项对照、2 项新立项候选。

## 2. 立项候选（晋升 TODO）

1. **【R234-A·MCP 注解对齐】tools/list 输出 MCP 规范 annotations**：readOnlyHint（14 只读 op）、destructiveHint（plugin.api/workflow.execute）、idempotentHint（bridge.ping/favorites.list/favorites.add/daily.status 等天然幂等/可重复 op）。验收=Claude Desktop/Cursor 工具详情可见注解；mcp-server 测试断言注解字段。安全不变（服务端门控为准，注解只是 UI 建议——与 safety-gate「防线在 dispatch 层」不变量一致）。
2. **【R234-B·描述评测】MCP 工具描述质量走查**：用固定任务集（"记一杯水""查今日打卡"）在真机 host 观察工具选择准确率，描述不歧义即通过——依赖真机 AI host（等用户），登记暂缓。
