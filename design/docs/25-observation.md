## 判读口径（给维护者）

- **净节省时间** = 手动耗时（复制→切窗→粘贴 ≈15s）× 次数 − (自动化耗时 + 修正耗时)
- **卡点优先级** = 出现频率 × 阻断程度——最高频卡点就是下一个开发项
- 连续两周 0 使用 → 主动询问原因（退出条件判据，docs/26 §8）
