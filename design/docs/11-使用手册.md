# 使用手册：Quicker × 思源动作（安装 → 配置 → 日常使用）

> 面向使用者。开发者请看 docs/03（蓝图）与 05（超级面板方案）。

## 1. 前置条件

| 项 | 要求 |
|---|---|
| Quicker | **V2（2.x）**，本套设计按 V2 文档编写（开发验证机 2.2.23） |
| 思源 | ≥ 3.8.x；使用期间保持运行（可托盘） |
| 内核地址 | 默认 `http://127.0.0.1:6806`（思源默认端口，无需改动——早前"本机 1568 非默认"的记录已作废，R21 真机实证） |
| API Token | 思源「设置 → 关于 → 复制 API 令牌」；或本机 `%APPDATA%\siyuan\env` 里的 `SIYUAN_TOKEN` |
| 可选 | 小驴快门（解锁插件命令层与数据动作）：从 [GitHub Releases](https://github.com/ai68298100/siyuan-quickgate/releases) 下载 package.zip 手动导入，集市暂缓上架 |

## 2. 首次安装（3 分钟）

1. **导入动作**：从分享链接安装，或在 Quicker 面板空白按钮右键 → 粘贴动作。
2. **贴 Token**：首次运行动作会引导粘贴 API 令牌（存入动作配置，不上传）。
3. **自动发现**：动作会自动识别日记笔记本与收集箱（显示识别结果让你确认）；识别不到时手填一次，之后永久记忆。
4. **试一发**：按 `Alt+S`（快速捕获）→ 输入一句话 → 思源今日日记出现 `- HH:mm 内容` 即成功。

### 自己动手搭建的推荐顺序（当前阶段：动作未分享，需按蓝图自建）

> 提速：Quicker 2.2.0+ 暂存区「用 AI 写」+ [docs/03 附A 提示词](../docs/03-动作蓝图.md) 先生成骨架，再按蓝图核对 HTTP 细节。

1. **先搭子程序** `SY·内核请求`（docs/03 §0）——所有动作的唯一内核入口，一处维护处处生效。
2. **再搭 P0-1 快速捕获**（最简、最快见效）——跑通即验证 Token/端口/日记笔记本三件事。
3. 依次 P0-4 打开日记 → P0-2 划词摘录 → P0-3 快查 → P0-5 图片入库（每个都先手动测试模式跑通再绑快捷键）。
4. SY-12 汇总待办 → SY·分拣收集箱（`fj`）——日常价值最高的两个。
5. **装快门并开桥**（§5）后，再搭打卡/人脉/面板——面板（docs/05）依赖前面的动作与子程序，放最后。
6. 每搭完一个动作：跑一次失败分支（改错 Token 试一次），确认错误提示符合 §6 自检表。

## 3. 日常触发方式

| 方式 | 说明 |
|---|---|
| 全局快捷键 | `Alt+S` 捕获 / `Alt+Q` 超级面板（可在 Quicker 改） |
| 文本指令 | `syq` 面板 · `sy` 快查 · `jl` 记日记 · `zl` 摘录 · `dk` 打卡 · `rm` 人脉 · `db` 待办汇总 · `tj` 体检 |

## 4. 动作速览

| 动作 | 干什么 | 去哪了 |
|---|---|---|
| 快速捕获 | 一句话/多行 → 今日日记 | `- HH:mm 内容` |
| 划词摘录 | 选中文字+来源 → 收集箱 | 引用块 + 来源行；可选复制 `siyuan://` 块链 |
| 全局快查 | 关键词搜思源并跳转 | `sql:` 前缀 = AI 生成只读 SQL（走思源内置 AI） |
| 剪贴板图片入库 | 截图 → assets + OCR | `![OCR文本](路径)` —— 图片内容可被全文搜索 |
| 汇总日记待办（SY-12） | 近 N 天未勾选待办 → 今日日记 | 汇总块 + 原文链接 |
| 数据体检（SY-13） | 空文档/重复标题/长期未动 → 只读报表 | 不自动删除任何东西 |
| 一键打卡（需快门） | 选事项 → 记录 → 报连击天数 | `source=api`（上游白名单），`externalRef` 幂等防重 |
| 记人脉互动（需快门） | 输入参与人 → 记共同交集 | 未入库的人自动收编 |
| 超级面板 | 上面全部的菜单入口 | 思源内全量菜单 / 思源外精简集 |

## 5. 小驴快门（可选增强）

1. 安装并启用快门 → 打开其设置 → **开启外部命令桥**（默认关，安全设计）。
2. 验证：`node tools/lv-cli.mjs ping`（仓库 tools/ 目录，需设 `SIYUAN_URL/SIYUAN_TOKEN` 环境变量）→ 返回 `recorded` 即通。
3. 开启后动作自动升级：一键打卡拿到连击天数、记人脉拿到收录人数、面板多出「全部插件命令」搜索。
4. 设置页三个排障按钮：**队列状态**（累计执行分账+平均耗时）、**导出诊断包**（脱敏 JSON 到剪贴板，求助时直接粘贴）、**生态清单版本**（各小驴插件清单版本×实装版本对照，升级后对不上就点它）。
5. 事件流（可选）：装打卡 ≥18.16 后，快门自动把打卡记录/删除事件物化到事件流，`lv-cli.mjs events pull` 可拉取（自动化编排的数据源）。
6. AI 助手接入（可选，v0.7.0+）：快门内置 MCP 服务器——在 Claude Desktop / Cursor 中配置后，AI 可直接打卡/记人脉/搜思源/跑工作流。默认 13 个只读工具；写工具需设环境变量 `LV_MCP_WRITE=1`。配置方法见 [快门仓库 src/mcp/README](https://github.com/ai68298100/siyuan-quickgate/blob/main/src/mcp/README.md)。

## 6. 错误自检表

| 症状 | 原因 | 处理 |
|---|---|---|
| 「思源未运行」 | 内核没开 | 启动思源；动作会自动重试一次 |
| 401/令牌无效 | Token 改过 | 思源「设置→关于」重新复制；动作会先自动重读本机 env 再引导手填 |
| `not exist` | 收集箱/日记笔记本被删 | 面板设置 → 重新配置；或跑 SY·诊断看发现结果 |
| `busy` | 内核忙 | 动作自动重试 ≤3 次；仍失败稍后再试 |
| 桥命令 `timeout` | 快门桥未开 / 确认框没人点 | 检查快门设置桥开关；确认弹窗 30 秒不点=拒绝 |
| 图片下载/上传失败 | 网络或站点点图 | 查看通知里的具体原因；重试 |

## 7. 隐私

- 所有数据只写进你本机的思源工作空间；Token 只存本机动作配置。
- AI 快查（`sql:` 前缀）走**你自己配置的思源内置 AI**；不配置则该功能不启用。
- 快门桥文件仅在本机工作空间内；不开启「外部命令桥」时无任何外部通道。

## 附：参数化 siyuan:// 链接集（R1 §2-③ · Raycast Quicklinks 式 · R242 交付）

> 用途：在**无法运行动作的场景**（手机、浏览器、他人电脑）一键跳转思源；或嵌在日常笔记/日历/待办里回跳。
> 证据等级：`siyuan://blocks/{id}` = 源码多源实证（内核 export/treenode 与前端 protyle 均按此前缀路由）；其余路由 E1 待复核（3.7.3 起官方持续改进协议处理）。

### 主力模板（可放心用）

| 模板 | 说明 |
|---|---|
| `siyuan://blocks/{块ID}` | 打开任意块/文档（文档 ID 即其根块 ID）；最通用 |
| `siyuan://blocks/{文档ID}?focus=1` | 带查询参数形态（源码见 av/itemLink 的 `?params` 用法；具体键待复核） |

### 组合用法（先查 ID 再跳转）

块 ID 未知时，先用快门查 ID 再拼链接（面板 sql-url 分支或手动）：

```sql
SELECT id, content FROM blocks WHERE type='d' AND content LIKE '%关键词%' LIMIT 5
```

拿到 `id` 后拼 `siyuan://blocks/{id}`。日常高频跳转（今日日记/收集箱）已有更快路径：P0-4 动作 / 面板「打开今日日记」。

### 已知边界

- 手机端打开依赖思源 App 注册协议；PWA 场景用 `web+siyuan://` 变体（uTools-siyuan 插件同源做法，R3 §6.2）。
- 其余路由（history/search/cards 等）**待复核**后再录入，不凭想象扩表（别名表同纪律）。
