# 方向一：思源超级面板（综合启动器）· 完整设计

> 一个 Quicker 动作 = 思源全部功能和小驴生态能力的快速入口：内核功能直达 + 插件命令/能力直达 + 用户自定义常用项。
> 配合思源端「小驴快门」插件（[06](06-小驴快门-配合插件设计.md)）点亮插件命令层；没有插件时自动降级为纯内核面板。
> 本文是实现级设计：变量/缓存 schema、分发器逐步、占位符字典、错误流、调试与实测项。

## 1. 功能分层：什么叫"所有思源功能"

| 层 | 覆盖内容 | 通道 | 依赖 | 摘要延迟 |
|---|---|---|---|---|
| L1 内核功能 | 搜索、日记、文档 CRUD、模板、闪卡、数据库、同步、导出 | 内核 HTTP API（见 04） | 无 | 0（静态） |
| L2 导航目标 | 今日日记、收集箱、书签、标签、最近改动、笔记本树 | SQL / 专端点 + `siyuan://` | 无 | 动态拉取 |
| L3 插件命令 | 命令面板全部条目（含已注册的小驴插件与其他插件） | 快门 `commands.list/search/run` | 快门插件 | 缓存 5min |
| L4 自定义 | 固定文档、组合动作、外部程序 | 菜单配置 JSON | 无 | 0 |

L3 的价值：**跨插件、全局热键可达、可被文本指令直呼**——思源自带 Ctrl+P 做不到「在其他应用里唤起思源某插件的某命令」。

## 2. 面板结构（首版菜单树）

```
思源超级面板 (Alt+Q / 侧键 / 文本指令 syq)
├─ 📝 捕获与日记
│   ├─ 记一笔到今日日记        → appendDailyNoteBlock（ask 内容）
│   ├─ 打开今日日记            → SQL → siyuan://
│   ├─ 划词摘录到收集箱        → appendBlock（思源前台自动带选中）
│   ├─ 汇总近期待办            → SY-12（借鉴「汇总日记代办」）
│   └─ 剪贴板图片入库          → runaction → 独立动作
├─ 🔍 搜索与导航
│   ├─ 全文搜索…               → ask → fullTextSearchBlock → userselect → siyuan://
│   ├─ 标签浏览                → searchTag → 二级菜单 → 按标签搜文档 → 跳转
│   ├─ 书签                    → bookmark/getBookmark → 二级菜单 → 跳转
│   └─ 最近改动                → block/getRecentUpdatedBlocks → 二级菜单 → 跳转
├─ 📄 文档
│   ├─ 新建文档（选笔记本）    → lsNotebooks → ask 标题 → createDocWithMd → 打开
│   ├─ 从模板新建              → searchTemplate → 选择 → createDocWithMd
│   ├─ 文档大纲跳转            → outline/getDocOutline → 二级菜单 → siyuan://focus块
│   └─ 打开收集箱              → siyuan://blocks/<配置ID>
├─ 🫏 小驴（L3，门控显示）
│   ├─ 一键打卡…               → 快门 checkin.items → userselect → checkin.record → checkin.summary notify
│   ├─ 记一笔人脉互动…         → runaction 独立动作
│   ├─ 雷切：切换器/工作台/恢复现场 → cmd commands.run
│   └─ 全部插件命令…           → bridge commands.search → userselect → run
├─ 🧩 插件命令（L3）
│   ├─ 按插件分组子菜单        → commands.list 缓存
│   └─ 全部命令搜索…           → 同上 search
└─ ⚙️ 系统
    ├─ 诊断                    → SY·诊断（一键体检：内核/令牌/快门/桥/配置发现）
    ├─ 立即同步 / 同步状态     → sync/performSync、getSyncInfo
    ├─ 闪卡复习                → riff/getRiffDueCards(全部卡包) → notify 到期数 + 打开卡包
    ├─ 数据体检                → SY-13 只读报表（借鉴「无效数据处理」）
    ├─ 导出备份                → export/exportData → 打开文件夹
    └─ 面板设置…               → 打开配置 JSON 编辑
```

动态项策略：静态项直接渲染；动态项打开面板时并行拉取，各自 800ms 超时 + 独立缓存；失败显示「（不可用）」占位不阻塞整面板。

## 3. Quicker 状态与缓存 schema（statestorage）

| 键 | 内容 | 写入时机 | TTL |
|---|---|---|---|
| `sy_url` / `sy_token` | 内核地址 / 令牌 | 首次运行读 `%APPDATA%\siyuan\env`；用户可在面板设置覆盖 | 永久 |
| `nb_diary` | 日记笔记本 ID | 首次用到时 `lsNotebooks` 让用户选一次 | 永久（可重选） |
| `inbox_doc` | 收集箱文档 ID | 首次用到时 SQL/选择器确定 | 永久 |
| `cache_bookmarks` | 书签 JSON | 面板打开 | 300s |
| `cache_tags` | 标签 JSON | 面板打开 | 300s |
| `cache_commands` | 快门命令树 JSON | 面板打开（L3） | 300s |
| `gate_quickgate` | 快门 ping 结果 | 面板打开 | 60s |
| `sy_alive` | 上次 version 探测时间戳 | 每次面板打开 | — |

## 4. 动作主流程（步骤级）

| # | 模块 | 内容 | 失败分支 |
|---|---|---|---|
| 1 | C# 赋值 | 读 statestorage 配置 | — |
| 2 | HTTP | `GET {sy_url}/api/system/version`，超时 300ms | → §6.1 思源未运行流程 |
| 3 | 并行子程序×4 | 书签 / 标签 / 快门ping / （可选）今日日记ID；各自 try/catch + 缓存 | 静默降级为占位项 |
| 4 | C# | 按 [templates/superpanel-menu.json](../templates/superpanel-menu.json) 结构 + 动态数据 + 门控，产出菜单列表变量（每项=显示文本）与载荷词典（显示文本→`{t,v}`） | — |
| 4b | C# | **双 profile 过滤**（08-O9）：思源前台（SiYuan 场景）显示全量菜单；其他程序前台显示精简集（捕获/快查/打卡/人脉/诊断/设置），菜单组带 `"profile":"global"` 标记 | — |
| 5 | showmenu / userselect | 弹出菜单（见 §7 实测项 A：两种实现都给） | 用户 Esc → 终止 |
| 6 | 子程序 `SY·路由` | 按载荷 `t` 分发（§5） | 统一错误 notify |
| 7 | notify | 成功/失败中文反馈 | — |

## 5. 分发器 `SY·路由`（子程序步骤表）

| 载荷 t | 步骤 | 备注 |
|---|---|---|
| `http` | jsonextract 端点/请求体 → 占位符解析（§5.1）→ `SY·内核请求` → 可选 `thenMenu`（把响应数组转二级菜单）或 `then`（继续路由） | thenMenu 支持书签/标签/最近 |
| `sql-url` | `SY·内核请求` 跑 SQL → 取 `data[0].root_id` → `openurl siyuan://blocks/<id>` | 空结果 → notify「没有找到，先在思源里建一次日记」 |
| `url` | `openurl {v}`（占位符已解析） | |
| `bridge` | `LV·发命令` → `LV·取回执`：普通数据 op 8s；无确认的快门命令 1.2s；`commands.run` 可能弹确认，等待上限 35s 或先回 `pending` 后按原 id 取回 → 按 `then` 分发 | timeout/pending 都不得换新 id 自动重试；迟到回执要能关联原命令 |
| `cmd` | 经快门 `commands.run`（即 bridge 特例，args={plugin,command}） | 确认开关开时思源端会弹确认 |
| `act` | `runaction {v.actionName}` | 转跳方向二独立动作 |

### 5.2 `then` 续分类型（bridge 命令回执后的下一步；R12 菜单模板在用，此处补契约）

| then.t | 输入（回执 data） | 步骤 |
|---|---|---|
| `userselect-record` | `checkin.items` → `{items:[{id,name,…}]}` | userselect 列事项 → 选后发 `checkin.record`（幂等）→ notify「✓ 已打卡 <事项名>」 |
| `userselect-run` | `commands.search` → `{commands:[{plugin,command,title}]}` | userselect 列命中命令 → 选后发 `commands.run`（确认门控生效）→ notify 回执 message |
| `notify-summary` | `checkin.summary` → 汇总对象 | C# 拼一行摘要（连击/今日完成数）→ notify；字段缺失降级显示原始 JSON 截断 |
| （thenMenu，已有） | 数组响应 | 书签/标签/最近三种映射见菜单模板 remark |

> 空数据处理：`checkin.items` 空 → notify「今天没有待打卡事项」；`commands.search` 零命中 → notify「没有匹配的命令」。

### 5.1 占位符字典（http/url 载荷统一解析）

| 占位符 | 解析为 |
|---|---|
| `{日记笔记本ID}` `{收集箱文档ID}` | statestorage 配置 |
| `{今天}` `{日期时间}` `{时间}` | yyyy-MM-dd / yyyy-MM-dd HH:mm / HH:mm |
| `{ask:提示语}` | 执行前 userinput 弹窗，结果同时存 `{ask值}` |
| `{选中文本}` `{来源窗口}` | 划词场景注入；空则提示先选中 |
| `{clipboard}` | 当前剪贴板文本 |
| `{选中标签}` `{选中书签块ID}` `{选中块ID}` | `thenMenu` 二级菜单的选择结果 |

## 6. 降级与错误流

### 6.1 思源未运行（toggle 语义，借鉴「打开指定工作空间」）
msgbox「思源没在运行。启动它吗？」→ 是：`run {用户配置的思源exe路径}`（默认 `C:\Program Files\SiYuan\SiYuan.exe`，实测项 B）→ 等 8s 重探 version → 恢复流程；否 → 终止。
**toggle 增强**：思源已在前台时触发面板快捷键 → 最小化思源（再次触发恢复/启动），形成「一键呼出/收起」；多工作空间按**窗口标题**（思源窗口标题含工作空间名）精确匹配激活。用户配置里可关掉询问（改为直接 `siyuan://` 拉起退出）。
**等待窗口步骤（Quicker 2.2.1+）**：`run` 拉起思源后接「等待窗口」步骤（按标题含「思源」等待窗口出现/前台，超时 10s），替代"等 8s 重探"的盲等——原生状态等待更可靠，超时再走 version 探测兜底；旧版 Quicker 回退原延时方案。

### 6.2 令牌无效（401/403）
notify「令牌无效」→ `openurl siyuan://settings/about`（打开思源设置-关于）→ userinput「粘贴新令牌」→ 写 statestorage → 重试原请求一次。

### 6.3 快门缺席（L3 门控）
面板打开时 `bridge.ping`（1s 超时）失败 → `gate_quickgate=false` → 🫏/🧩 组替换为单项「安装小驴快门」→ 打开用户配置的 GitHub 安装说明；仓库尚未发布时显示「安装说明尚未发布」。轻量备选：`/api/petal/loadPetals` 判断装没装（装了但桥没开时提示「在快门设置里打开外部命令桥」）。

### 6.4 通用（04 §8 表）
内核忙 busy → 重试 ≤3；not exist → 提示重配收集箱/日记笔记本；其余展示 msg 原文。

## 8. 性能预算（目标：冷 ≤1.2s，热 ≤0.5s）

| 阶段 | 冷 | 热（命中缓存） |
|---|---|---|
| version 探测 | 50ms | 50ms |
| 4 路并行动态拉取 | ≤800ms（最慢一路决定） | ~0（缓存直读） |
| 菜单构建（C#） | <50ms | <50ms |
| showmenu 渲染 | ~100ms | ~100ms |
| L3 桥命令往返 | 普通命令 0.75~1s；含确认的 `commands.run` 最长 35s 或异步 pending | 同左 |

命令类动作（bridge/cmd）按 op 选择等待策略；notify 文案写「已提交/已执行」而非在未收到回执时声称「已完成」。

## 9. 调试与日志

- 动作内置「调试模式」布尔变量（用户配置）：开启后每个 HTTP 请求/响应追加写 `%TEMP%\sy-quicker.log`（时间、端点、状态码、前 500 字符）。
- 分发器每步用 `log` 模块输出到 Quicker 运行日志（动作编辑器可见）。
- 「面板设置…」菜单项提供：打开日志文件 / 清空缓存 / 重新配置笔记本与收集箱 / 编辑菜单 JSON。

## 10. 分享卫生（发布到动作库时）

1. 用户配置（Token/路径/ID）全部走 Quicker「用户配置」机制，分享包不含值。
2. 内置默认菜单 JSON 不含个人文档 ID（占位符留空并在首次运行引导配置）。
3. README 写明：免费版 Quicker 的功能限制、需要思源 ≥3.8.x、需要小驴快门解锁 L3（可选依赖）。
4. 提供动作页截图 + 首次运行向导（三个 ask 完成：令牌粘贴、日记笔记本、收集箱）。

## 11. 与方向二的关系

方向二独立动作 = 面板 `act:` 叶子。共享子程序 `SY·内核请求`/`LV·发命令`/`LV·取回执`/`SY·路由`（Quicker 链接动作/子程序机制，一处维护）。面板动作可以只发不发——纯消费独立动作也可反向注册进菜单 JSON（用户自加 `act` 项）。
