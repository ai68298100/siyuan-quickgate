## 小驴快门（Lv QuickGate）：让 Quicker、手机、脚本都能调用你的思源和小驴插件

### 它解决什么问题

思源插件的能力（命令面板命令、打卡记录、人脉互动）都活在窗口里，外部程序够不着。市面上的桥接要么逐插件开发、要么只能干瞪眼。**小驴快门是一个中枢插件**：装一个，全部插件零改动地获得统一的外部入口——

- **Quicker**：一键打卡（报连击天数）、记人脉互动（自动收编新人）、超级面板直呼任意插件的命令
- **iOS 快捷指令 / Tasker / HA**：同一个 NDJSON 契约直发命令，手机拍照后语音记一笔到今日日记
- **脚本党**：`tools/lv-cli.mjs`（node 零依赖）或 `Send-LvCommand.ps1`
- **思源内置 AI / 其他插件**：registry/diagnostics/events 白名单事件与受控工作流

### 安全设计（默认关、可审计）

- 外部命令桥默认**关闭**；命令执行默认弹确认（30 秒不点=拒绝）；全部执行进审计日志
- 只消费插件公开注册能力与公开桥方法，**不读取任何插件的私有存储**
- 高级透传独立开关 + 允许名单

### 质量口径

47 个单元测试（队列并发追加不丢失、幂等持久化、单飞轮询、TTL、失败停止）；CI 全绿；协议契约机器可读。

### 安装（手动，集市暂缓）

GitHub：https://github.com/ai68298100/siyuan-quickgate → Releases 下载 `package.zip` → 思源「设置 → 集市 → 下载页 → 导入安装包」→ 启用后开桥。

配套 Quicker 动作与思源端小驴生态（打卡/人脉/雷切/管家/闪卡/考试/拾遗）的联动示例见仓库 README。
