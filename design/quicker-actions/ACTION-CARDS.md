# 动作卡（R106-P0）—— 用户视角的一页说明

> 验收口径：**用户不看模块名也能判断是否适合自己**。每张卡：用户任务/触发/输入/输出/写入位置/成功证据/失败恢复/手动替代。
> 参考件：`reference/`（变量连线表见各文件头注）。子程序（供动作内部调用）见文末速查表。

---

## SY·划词摘录（G2 样板）
- **用户任务**：网页/文档里看到重要段落，一键存进收集箱，永远可找回。
- **触发**：划词工具条按钮 / 思源前台快捷键。
- **输入**：选中文本（四级兜底）；来源窗口自动记录。
- **输出**：收集箱新块（引用块+来源行）。
- **写入位置**：收集箱文档（未配置时自动发现，`config.discover`）。
- **成功证据**：notify「✓ 已入收集箱：预览」+ `块ID` 变量（可跳转）。
- **失败恢复**：401→令牌引导；未配置收集箱→发现+手填提示；思源未运行→SY·思源未运行分支拉起。
- **手动替代**：手动复制→思源 Ctrl+V。

## SY·快速捕获（P0-1）
- **用户任务**：闪念一句话，带时间戳进今日日记，不打断心流。
- **触发**：全局快捷键（建议 Alt+S）/ 文本指令 `jl`。
- **输入**：userinput 多行内容；可选 `#前缀` 路由到指定文档（R3）。
- **输出**：日记新列表块（`HH:mm 内容`）；可落指定标题下（R6 变体，零命中回退文末）。
- **写入位置**：今日日记（appendDailyNoteBlock 自动建日记）/ 路由目标文档。
- **成功证据**：notify「✓ 已入今日日记」/「✓ 已按路由入档」。
- **失败恢复**：同划词摘录；落点标题未命中自动回退文末并说明。
- **手动替代**：打开日记手敲。

## SY·全局快查（P0-3）
- **用户任务**：任何窗口下快速搜思源内容并跳转高亮。
- **触发**：文本指令 `sy` / 全局快捷键。
- **输入**：关键词；`sql:` 前缀=只读 SQL 直查（安全过滤：单语句+禁止写词+强制 LIMIT）。
- **输出**：候选列表（userselect）→ 跳转 `siyuan://blocks/{id}`。
- **写入位置**：无（只读）。
- **成功证据**：命中数提示；三级降级（全文→模糊 SQL→提示 sql:）。
- **失败恢复**：零命中给 sql: 引导；401/未运行同上。
- **手动替代**：思源内 Ctrl+P 搜索。

## SY·打开今日日记（P0-4）
- **用户任务**：一键到今天的日记（没有就建）。
- **触发**：鼠标侧键 / 快捷键。
- **输入**：无（today 精确匹配 SQL）。
- **输出**：跳转到日记（或收集箱，目标可配）。
- **写入位置**：日记不存在时创建（写一个空块触发）。
- **成功证据**：思源跳转并高亮日记文档。
- **失败恢复**：定位失败=索引延迟（重试一次即可）；收集箱未配置=发现+手填提示。
- **手动替代**：思源侧栏点日记。

## SY·剪贴板图片入库（P0-5）
- **用户任务**：截图/复制的图进思源资产，OCR 后可被全文搜索。
- **触发**：快捷键 / 场景页按钮。
- **输入**：剪贴板图片 + OCR 文本（Quicker OCR 模块，过 SY·OCR清理）。
- **输出**：assets 资源 + 日记图片块（**OCR 在 alt**，搜 OCR 词即命中图）。
- **写入位置**：`/assets/` + 今日日记。
- **成功证据**：notify「✓ 图片已入库（OCR alt 可检索）」+ 资源路径。
- **失败恢复**：无图片/上传失败/写日记失败三分支提示；图片已上传时仅日记写入需补。
- **手动替代**：思源拖拽图片（无 OCR alt）。

## SY·汇总日记待办（SY-12）
- **用户任务**：把最近 N 天日记里没勾的待办汇总成一张清单，回链原文。
- **触发**：文本指令 `db` / 快捷键。
- **输入**：回看天数（默认 7）。
- **输出**：今日日记「## 待办汇总（近N天）」块，每条带 `[→](siyuan://blocks/{id})` 回链。
- **写入位置**：今日日记。
- **成功证据**：notify「✓ 已汇总 N 条待办」。
- **失败恢复**：零待办明确提示；SQL/写入失败中文原因。
- **手动替代**：手动翻日记。

## SY·数据体检（SY-13）
- **用户任务**：体检空文档/重复标题/最早文档，得到只读报告。
- **触发**：文本指令 `tj` / 超级面板 ⚙️。
- **输入**：体检项（默认全跑）。
- **输出**：Markdown 报告（数量+样例+siyuan:// 链接 + 「可能误判」提示）。
- **写入位置**：**无——只读不删**（清理引导原作「无效数据处理」）。
- **成功证据**：「✓ 未发现问题」/「⚠️ 发现待复核项」。
- **失败恢复**：各项独立，单项失败不影响其余。
- **手动替代**：原作动作。

## 子程序速查（动作内部调用；详见 reference/README.md）

| 子程序 | 一句话 | 关键输出 |
|---|---|---|
| SY·内核请求 | 内核调用唯一入口（401 自愈 v1.1） | 文本结果/错误提示 |
| LV·发命令 / LV·取回执 | 桥命令收发（幂等 id/不换 id 重试） | 命令 id / 回执 |
| SY·路由 | 超级面板六分支分发器 | 后续动作指令/结果数据 |
| SY·反向触发 | 反向拉起 Quicker 动作（668 API） | 响应文本 |
| SY·思源未运行分支 | 探测→询问→启动→重探 | 思源已运行 |
| SY·粘贴守卫 | 粘贴前目标窗口确认 | 允许粘贴 |
| SY·预检 | 运行前能力预检（内核/令牌/桥/插件） | 预检报告/失败项 |
| SY·OCR清理 / SY·文本规范化 | OCR 后处理 / 规则化清理 | 清理结果 / 新文本 |
| SY·研究来源卡 / SY·文件项目索引 / SY·变更报告 | 结构化写入三件 | 块ID/索引表/变更报告 |
| SY·WebDAV传输 | 远程 download/upload/list | 本地文件/远程列表 |
| SY·Office选区 | Word/WPS·Excel/WPS 选区读取 | 选区文本/表格Markdown |
| SY·日志轮转 | 本地日志（1MB 滚动） | 日志路径 |
| SY·占位符解析 / SY·路由前缀解析 | 载荷模板/多目标路由解析 | 解析结果 |

## 完成判据五级（R106-P0·完成判据 × 回执语义映射）

| 级别 | 证据载体 |
|---|---|
| 1 动作已调用 | 动作开始执行（Quicker 运行记录） |
| 2 owner 已接受 | 桥回执 `recorded`（非 rejected/unsupported） |
| 3 业务已写入 | 回执 `data`（块ID/记录数），owner 插件入库 |
| 4 结果可回读 | `siyuan://blocks/{id}` 可打开 / events.pull 可查 |
| 5 用户已定位 | 跳转高亮后用户可见（notify+openurl 双通道） |

> notify ≠ 证据：Quicker notify 只证明"动作跑完了"；写入证明永远以快门/业务回执为准（红线：未知不得改写为成功）。
